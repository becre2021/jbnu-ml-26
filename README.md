# jbnu-ml-26

Machine learning practice notebooks for weeks 2–4, covering linear regression, binary and multiclass classification, and Bayesian machine learning with PyTorch. The regression and classification notebooks implement gradient descent manually; the Bayesian notebook compares posterior sampling methods and visualizes predictive uncertainty.

## Notebooks

| Week | Notebook | Dataset | Main topics |
| --- | --- | --- | --- |
| 2 | [Linear regression](week2_linear_reg.ipynb) | synthetic samples | Squared error, closed-form solution, gradient descent |
| 3 | [Logistic regression](week3_logistic_reg.ipynb) | synthetic binary labels | Sigmoid, binary cross-entropy, classification threshold |
| 4 | [Multiclass classification](week4_multicls_classification.ipynb) | MNIST handwritten digits | Softmax, multiclass cross-entropy, mini-batch training |
| 4 | [Bayesian logistic regression: MCMC and HMC](week4_bayesian_logistic_mcmc_hmc.ipynb) | synthetic binary labels | Gaussian prior, posterior sampling, Random-Walk Metropolis, HMC, predictive uncertainty |
