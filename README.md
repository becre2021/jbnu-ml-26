# JBNU Machine Learning & Bayesian Machine Learning (2026)

Jupyter notebooks for the 2026 Machine Learning and Bayesian Machine Learning courses at JBNU.

## Machine Learning

| Week | Notebook | Dataset | Main topics |
| --- | --- | --- | --- |
| 2 | [Linear regression](week2_linear_reg.ipynb) | Synthetic data | Squared error, closed-form solution, gradient descent |
| 3 | [Logistic regression](week3_logistic_reg.ipynb) | Synthetic binary data | Sigmoid, binary cross-entropy, classification threshold |
| 4 | [Multiclass classification](week4_multicls_classification.ipynb) | MNIST handwritten digits | Softmax, multiclass cross-entropy, mini-batch training |
| 5 | [Support vector machines](week5_svm_binary.ipynb) | Synthetic binary data | Hard and soft margins, primal and dual optimization, support vectors |
| 11 | [Neural network regression](week11_mlp_regression.ipynb) | Noisy sine data | ReLU, backpropagation, mini-batch SGD, `torch.nn` |
| 12 | [Convolutional neural networks](week12_cnn_cifar10.ipynb) | CIFAR-10 images | Convolution, pooling, batch normalization, residual connections |
